# Boost Bracket 管理UI 仕様書 (2025-10-28 時点)

## 共通事項
- ベースURL: `http://localhost:5173/admin`
- Basic認証: `local / local`
- 画面上部には常時パンくず／戻るリンクを配置 (`← 管理トップに戻る` など)
- フォーム操作後はフラッシュメッセージで成功・失敗を通知
- JSONインポート/エクスポート機能はすべての管理画面に標準搭載
  - エクスポート欄は読み取り専用テキストエリア
  - インポート欄はJSON文字列を貼り付けて「取り込み」ボタンで実行
  - 無効データはスキップ、既存レコードは上書き

---

## 管理トップ `/admin`

### 構成
- ページタイトル: `Boost Bracket 管理トップ`
- 説明文: 管理全般の導線案内
- **イベント選択ブロック**
  - セレクトボックス: 既存イベント一覧
  - 各種管理画面へのボタン群
    - `プレイヤー管理へ`
    - `ペア管理へ`
    - `チーム管理へ`
    - `団体戦管理へ`
    - `試合ログへ`
    - `統計表示へ`
    - `トーナメント設定へ`
  - イベント未選択時は全ボタン disabled
- **新規イベント作成フォーム**
  - `イベント名`（必須）
  - `スラッグ`（任意）
  - `イベントを作成` ボタン
  - 成功時はセレクトに追加、作成完了メッセージ表示
- **登録済みイベントリスト**
  - テーブル項目: `ID / イベント名 / Slug / 作成日`

---

## プレイヤー管理 `/admin/events/{eventId}/entries/players`

### ヘッダ
- タイトル: `プレイヤー管理`
- `イベントID` 表示
- `← 管理トップに戻る` リンク

### フォーム: プレイヤーを追加
- `名前`（必須）
- `メモ`（任意）
- `追加` ボタン

### 登録済みプレイヤーリスト
- 件数表示 `(0)` など
- 各プレイヤー行
  - `名前`（インライン編集用 input）
  - `メモ`（インライン編集用 input）
  - `更新` / `削除` ボタン
- 操作成功時メッセージ: 例 `プレイヤー「プレイヤーA」を追加しました。`

### JSON操作
- `エクスポート` テキストエリア／ダウンロードリンク
- `インポート` テキストエリア＋ `取り込み` ボタン
- `JSONエディタを開く` ボタン（モーダルで編集想定）

---

## チーム管理 `/admin/events/{eventId}/entries/teams`

### ヘッダ
- タイトル: `チーム管理`
- 構成はプレイヤー管理と同一

### フォーム: チームを追加
- `チーム名`（必須）
- `追加` ボタン

### 登録済みチームリスト
- 件数表示
- 各チーム行
  - `チーム名`（インライン編集）
  - `更新` / `削除` ボタン
- 操作成功メッセージ例
  - `チーム「チームA」を追加しました。`
  - `チーム「チームA改」を更新しました。`

### JSON操作
- プレイヤー管理と同様の構成

## 団体戦管理 `/admin/events/{eventId}/team-battles`

### ヘッダ
- タイトル: `団体戦管理`
- `イベントID` 表示

### 団体戦作成フォーム
- `チームA` セレクト（必須）
- `チームB` セレクト（必須）
- `スロット数` セレクト（初期値3・範囲1〜5）
- `形式` セレクト（現状 `早稲田式` のみ）
- `タイブレーク` セレクト（`なし` / `代表戦`）
- `作成` ボタン

### 未登録時の表示
- チーム数が2未満: 作成フォームの代わりに注意文表示
  - `団体戦を作成するには、少なくとも2つのチームが必要です。`
  - `チーム管理ページ` への誘導リンク付き
- `登録済み団体戦 (0件)` / `まだ団体戦が登録されていません。`

### 注意点
- 実際に `チームA改 vs チームB` で `作成` 実行時、HTTP 500 エラーを確認
  - 現状仕様上は団体戦を作成できるはずだが、エラーハンドリングの改善が必要
