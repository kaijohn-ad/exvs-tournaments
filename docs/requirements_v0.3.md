# Boost Bracket 要件定義書 v0.3

## 概要/目的
- EXVSインフィニットブーストの小規模“身内大会”を、iPadで運営・可視化できるWebアプリ。
- MVPは素早い試用を優先し、仕様確定後に安価なホスティングへデプロイ。

## 決定事項（v0.3）
- 大会形式: シングルエリミのみ。
- 団体戦: 早稲田式。スロット数はデフォルト3（先鋒/中堅/大将）、上限5。
- 重複出場: 同一チーム内で「1名のみ2回出場」可。リセットは団体戦ごとに毎回。
- タイブレーク（偶数スロット時の同点）: 管理者が任意のペアを選択して代表戦を実施（設定でオン時）。
- 公開範囲: 観覧は認証なしの公開。乱数スラッグURLで共有。
- 管理・認証: 管理画面はBasic認証で保護。
- ブラウザ: Chrome（iPadはWebKit相当）。
- アプリ名: Boost Bracket（略称: BB）。
- デプロイ: Cloudflare Pages + Functions + D1。

## スコープ（MVP）
- 参加者/ペア管理
  - プレイヤー登録/編集/削除（管理画面）。
  - 2人ペア作成/編集/削除。CSV/JSON入出力。
- トーナメント（2on2、シングルエリミ）
  - 自動生成（ランダム/任意シード）、BYE付与、勝ち上がり反映。
  - 手動編集（対戦カード入替/参加者割当/結果修正）。
- 団体戦（早稲田式）
  - 対戦は常に「2チーム」のみで構成（MVP）。
  - スロット数（1..5）設定、ペア割当（固定ペア/即席ペア）。
  - 同一チームで「1名のみ2回出場」可の制約検証。
  - 代表戦（設定オン時）、管理者が任意ペアを選択。
- 進行管理/表示
  - 試合結果（勝者/スコア）入力で次工程に自動反映。
  - iPad最適表示（横/縦対応、タップ領域確保、D&D操作）。
- 認証/公開
  - 管理画面のみBasic認証。
  - 公開ビューは乱数スラッグURLで共有（GETのみ）。
- データ運用
  - 大会（Event）単位でデータを分離保存/復元。
  - JSONエクスポート/インポート。
- ログ/将来拡張
  - 試合ログを個人単位にも紐づけ保存（内部レーティングの素材）。

## 非機能要件
- iPadでストレスなく操作可能。
- 小規模人数で安定動作、5秒ポーリングで最新化。
- Basic認証の資格情報は環境変数/Secretで管理。
- コストは無料〜低額（Cloudflare無料枠を想定）。

## アウトオブスコープ（MVP）
- ダブルエリミ/スイス。
- リアルタイムWS配信（将来SSE/WSへ拡張）。
- 高度なレーティング（初期は未計算。まずはログ蓄積）。

## 受け入れ基準（MVP）
- トーナメントの作成/表示/編集/結果反映が可能。
- 団体戦（2チーム）でラインナップ設定、重複出場制約、代表戦が運用できる。
- 管理はBasic認証で保護、観覧は乱数スラッグURLで閲覧可能。
- 試合ログが個人まで追跡可能な形で保存される。

## 用語
- BYE: 参加数が2の冪に満たない場合の不戦勝枠。BYEを引いた参加者（ペア）は自動で次ラウンドへ進む。
