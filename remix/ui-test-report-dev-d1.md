## 確認事項

### データベース接続の確認

開発環境では、以下のロジックによりデータベースが選択される：

1. `remix/load-context.ts`: `cloudflare.env.DB` が存在する場合、D1データベースを使用
2. `remix/app/repositories/database.server.ts`: 
   - 開発環境では `NODE_ENV === 'development'` の場合はメモリストアを使用
   - `USE_MEMORY_STORE` が `'true'` の場合はメモリストアを使用
   - それ以外の場合はD1データベースを使用

### 開発用D1データベースの設定

- **データベース名**: `exvs-tournaments-dev`
- **Database ID**: `4d86595e-81c8-467c-900c-b474d6fa584f`
- **設定ファイル**: `remix/wrangler.toml` の `[env.dev]` セクション

## 重要な発見

### 開発環境でのデータベース選択ロジック

`remix/app/repositories/database.server.ts` の実装により、開発環境（`NODE_ENV === 'development'`）では**デフォルトでメモリストアが使用**されます。

現在の動作:
- ✅ イベント作成機能は正常に動作（メモリストアを使用）
- ✅ データはセッション中は保持される
- ⚠️ 開発用D1データベース（`exvs-tournaments-dev`）には書き込まれていない

開発用D1データベースを使用するには:
1. `USE_MEMORY_STORE` 環境変数を設定しない（または `false` に設定）
2. Cloudflareの開発プロキシでD1バインディングが提供されていることを確認
3. `NODE_ENV` が `development` 以外の場合、D1データベースが使用される

### 開発用D1データベースの直接確認

```bash
cd remix
npx wrangler d1 execute exvs-tournaments-dev --remote --env dev --command="SELECT * FROM events"
```

結果: データベースは正常にアクセス可能だが、開発環境のメモリストアのため、データはまだ書き込まれていない。
