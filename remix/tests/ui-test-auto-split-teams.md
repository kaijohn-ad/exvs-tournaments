### 2. チームのみ作成（団体戦作成なし） ✅
- **前提条件**: イベントに2名以上のプレイヤーが登録されている
- **操作**: 
  1. チームA名: 「白チーム」、チームB名: 「黒チーム」を入力
  2. 「同時に団体戦（勝ち抜き戦）を作成する」チェックボックスをOFF
  3. 「チーム分けを実行」ボタンをクリック
- **期待結果**: 2つのチームが作成され、プレイヤーが均等に分割される
- **確認項目**:
  - [x] 成功メッセージが表示される（例: 「チーム「白チーム」(3名)とチーム「黒チーム」(3名)を作成しました。」）
  - [x] チーム管理ページで新しく作成された2つのチームが表示される
  - [x] 各チームにプレイヤーが追加されている
  - [x] プレイヤー数が均等に分割されている（偶数の場合は均等、奇数の場合は1名差以内）
  - [x] 団体戦は作成されていない

### 3. チームと団体戦を同時作成 ✅
- **前提条件**: イベントに2名以上のプレイヤーが登録されている
- **操作**: 
  1. チームA名: 「赤チーム」、チームB名: 「青チーム」を入力
  2. 「同時に団体戦（勝ち抜き戦）を作成する」チェックボックスをON
  3. スロット数を「3」に設定
  4. 「チーム分けを実行」ボタンをクリック
- **期待結果**: 2つのチームと勝ち抜き戦形式の団体戦が同時に作成される
- **確認項目**:
  - [x] 成功メッセージが表示される（例: 「チーム「赤チーム」(3名)とチーム「青チーム」(3名)を作成しました。 団体戦（勝ち抜き戦）も作成しました。」）
  - [x] チーム管理ページで新しく作成された2つのチームが表示される
  - [x] 団体戦一覧に新しく作成された団体戦が表示される
  - [x] 作成された団体戦の形式が「勝ち抜き戦」として表示される
  - [x] 作成された団体戦のスロット数が「3」として表示される
  - [x] 作成された団体戦のチームA/Bが自動分割で作成されたチームと一致する

### 4. カスタムチーム名での作成 ✅
- **前提条件**: イベントに2名以上のプレイヤーが登録されている
- **操作**: 
  1. チームA名: 「赤チーム」、チームB名: 「青チーム」を入力
  2. 「チーム分けを実行」ボタンをクリック

### 5. エラーハンドリング: プレイヤー不足
- **前提条件**: イベントにプレイヤーが1名以下または登録されていない
- **操作**:

- **期待結果**: エラーメッセージが表示される
- **確認項目**:

  - [ ] チームは作成されない

### 6. エラーハンドリング: スロット数無効
- **前提条件**: イベントに2名以上のプレイヤーが登録されている
- **操作**: 
  1. 「同時に団体戦（勝ち抜き戦）を作成する」チェックボックスをON
  2. スロット数を無効な値（例: 10）に設定（ブラウザの開発者ツールで変更）
  3. 「チーム分けを実行」ボタンをクリック
- **期待結果**: エラーメッセージが表示される
- **確認項目**:
  - [ ] エラーメッセージ「スロット数は1〜5の範囲で指定してください。」が表示される
  - [ ] チームは作成されない

### 7. 作成後のチームメンバー確認
- **前提条件**: 自動チーム分けでチームを作成済み

- **期待結果**: 各チームにプレイヤーが正しく追加されている
- **確認項目**:
  - [ ] チームAにプレイヤーが追加されている
  - [ ] チームBにプレイヤーが追加されている
  - [ ] プレイヤーが重複していない（各プレイヤーは1つのチームにのみ所属）
  - [ ] 全プレイヤーがどちらかのチームに所属している

### 8. 作成後の団体戦ラインナップ設定 ✅
- **前提条件**: 自動チーム分けでチームと団体戦を同時作成済み
- **操作**: 作成された団体戦の「ラインナップ編集」リンクをクリック
- **期待結果**: ラインナップ編集画面で各スロットにプレイヤーを割り当てられる
- **確認項目**:
  - [x] ラインナップ編集画面が表示される
  - [x] 各スロット（スロット1〜スロットN）にチームA/Bのフォームが表示される
  - [x] 「個別プレイヤー」選択で、自動分割で作成されたチームのプレイヤーが選択可能
  - [x] ラインナップを設定できる

### 9. 複数回実行時の動作
- **前提条件**: イベントに4名以上のプレイヤーが登録されている
- **操作**: 
  1. 1回目の自動チーム分けを実行
  2. 2回目の自動チーム分けを実行（異なるチーム名で）
- **期待結果**: 新しいチームが追加で作成される
- **確認項目**:
  - [ ] 1回目で作成されたチームが残っている
  - [ ] 2回目で新しいチームが追加で作成される
  - [ ] 全プレイヤーが2回目のチーム分けにも含まれる（既存チームに所属していても再度分割される）

### 10. フォームのリセット
- **操作**: 
  1. チーム名を入力
  2. チェックボックスをONにする
  3. スロット数を選択
  4. 「チーム分けを実行」ボタンをクリック
  5. 成功後、フォームの状態を確認
- **期待結果**: フォームが初期状態に戻る
- **確認項目**:
  - [ ] チームA名が「チームA」に戻る
  - [ ] チームB名が「チームB」に戻る
  - [ ] チェックボックスがOFFに戻る
  - [ ] スロット数選択が非表示になる
