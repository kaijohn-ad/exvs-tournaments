## 確認された動作仕様

### クロスシード形式
ラウンド1のグループからラウンド2への勝者伝播は、以下のクロスシード形式で実装されている：

- **グループ1の勝者1** → ラウンド2のスロット1
- **グループ2の勝者1** → ラウンド2のスロット2
- **グループ1の勝者2** → ラウンド2のスロット3
- **グループ2の勝者2** → ラウンド2のスロット4

これにより、同じグループの勝者同士が早期に対戦することを避けている。
