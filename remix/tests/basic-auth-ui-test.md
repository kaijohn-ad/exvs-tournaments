# Basic認証 UI統合テスト

## テスト環境
- **サーバーURL**: http://localhost:5174
- **テスト対象**: `/admin` 配下のBasic認証機能
- **環境変数**: `BASIC_AUTH_USER` と `BASIC_AUTH_PASSWORD` が設定されている必要があります

## テストケース

### TC-BA-001: Basic認証が要求される（認証なしでアクセス）
**前提条件**: 
- サーバーが起動している（http://localhost:5174）
- `BASIC_AUTH_USER` と `BASIC_AUTH_PASSWORD` が設定されている

**テスト手順**:
1. ブラウザーで `http://localhost:5174/admin` にアクセス

**期待結果**:
- Basic認証ダイアログが表示される
- または、401 Unauthorized レスポンスが返される

**確認項目**:
- [ ] Basic認証ダイアログが表示される
- [ ] キャンセルした場合、アクセスできない（401エラー）

---

### TC-BA-002: 正しい認証情報でアクセス可能
**前提条件**: 
- サーバーが起動している
- `BASIC_AUTH_USER` と `BASIC_AUTH_PASSWORD` が設定されている

**テスト手順**:
1. ブラウザーで `http://localhost:5174/admin` にアクセス
2. Basic認証ダイアログに正しいユーザー名とパスワードを入力
3. OKをクリック

**期待結果**:
- `/admin` ページが正常に表示される
- 認証情報が正しく検証される

**確認項目**:
- [ ] 認証ダイアログが表示される
- [ ] 正しい認証情報を入力するとページが表示される
- [ ] 管理トップページの内容が正しく表示される

---

### TC-BA-003: 誤った認証情報ではアクセス不可
**前提条件**: 
- サーバーが起動している
- `BASIC_AUTH_USER` と `BASIC_AUTH_PASSWORD` が設定されている

**テスト手順**:
1. ブラウザーで `http://localhost:5174/admin` にアクセス
2. Basic認証ダイアログに誤ったユーザー名またはパスワードを入力
3. OKをクリック

**期待結果**:
- 認証が失敗し、再度認証ダイアログが表示される
- または、401 Unauthorized レスポンスが返される

**確認項目**:
- [ ] 誤った認証情報ではアクセスできない
- [ ] 認証ダイアログが再度表示される（または401エラー）

---

### TC-BA-004: `/admin` 以外のパスは認証不要
**前提条件**:

**テスト手順**:

2. 認証なしでアクセス

**期待結果**:
- Basic認証ダイアログが表示されない
- ページが正常に表示される

**確認項目**:
- [ ] Basic認証ダイアログが表示されない
- [ ] `/events` ページが正常に表示される
- [ ] 認証なしでアクセス可能
