1. **Winners Round 2の敗者の伝播ロジック修正**: `losersTargetRound = match.round + 1` → `losersTargetRound = match.round` に変更（Winners Round 2の敗者がLosers Round 2に正しく進出するように修正）
2. **Losers Round生成ロジック修正**: 4ペアの場合、Losers Round 3を生成せず、Losers Round 2を最終ラウンドとするように変更。`losersRound <= totalRounds * 2 - 1` → `losersRound <= totalRounds`に変更。`losersCurrentState`の初期化も修正（`losersRounds[0]`の代わりに、`losersRound1WinnerCount`を使用）
3. **participant typeの正規化**: `'empty'`の代わりに`'bye'`を使用するように統一（bye試合の自動完了処理も`'bye'`をチェックするように修正）
