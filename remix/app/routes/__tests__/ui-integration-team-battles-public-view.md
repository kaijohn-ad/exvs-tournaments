- テスト対象: 公開イベント一覧 (`/events`) と団体戦ボード (`/events/:eventId/team-battles/:battleId/board`)

#### 1.2 団体戦カードの内容
- [x] チーム名が「チームA名 vs チームB名」形式で表示される

- [x] 結果バッジが表示される（完了時）
- [x] スロット数が表示される
- [x] 「詳細を見る →」リンクが表示される

#### 1.3 団体戦リンクの動作
- [x] 団体戦カードのリンクURLが `/events/:eventId/team-battles/:battleId/board` である
- [x] リンクのURLが正しい

#### 2.2 スコアボード
- [x] スコアボードセクションが表示される
- [x] チームAの勝数が正しく表示される

#### 2.3 ラインナップ表示

#### 2.4 試合一覧
- [x] 試合がある場合、試合一覧セクションが表示される

#### 2.5 自動更新機能
- [x] ページが5秒ごとに自動更新される（最終更新時刻が更新される）
