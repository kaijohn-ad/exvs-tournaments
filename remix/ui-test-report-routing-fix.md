## 実装確認事項

### 修正内容

1. **公開ブラケット loader のイベント所属チェック追加**
   - ファイル: `remix/app/routes/events.$eventId.tournaments.$tournamentId.bracket.tsx`
   - 変更: `tournament.eventId !== eventId` のチェックを追加
   - 効果: 不一致時に404を返すことで、セキュリティとデータ整合性を確保

2. **イベント一覧のリンクを `<Link>` に変更**
   - ファイル: `remix/app/routes/events._index.tsx`
   - 変更: `<a href>` を `<Link to>` に変更
   - 効果: SPA遷移によるUX向上とパフォーマンス改善

### テストカバレッジ

- ✅ 正常系: 正しいID組み合わせでのブラケット表示

- ✅ ナビゲーション: SPA遷移の動作確認
